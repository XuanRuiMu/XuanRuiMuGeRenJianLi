# 经历与工作方式

## 开发方法论：AI Agent 全流程工程
于翔堃的全部项目均由 AI Agent 自主开发，其工作方式是一套可复现的工程体系而非简单对话：
1. 需求澄清 → 可验证目标定义（停止条件必须可机器验证）
2. 任务拆解 → 粗粒度功能点列表持久化到 PROGRESS.md（外部状态文件，绕开会话上下文限制）
3. 自主循环 → 主代理编排 + 子代理执行 + 每功能点测试/审查/压缩归档
4. 熔断保护 → 同一问题修复超 5 次跳过、总循环达上限即停、阻塞立即上报
5. 交付前元循环 → 审查本次暴露的弱点并沉淀为约束规则

## 代表性复杂任务战绩
- 在一次会话中完成简历站+游戏平台的 10 个功能点迭代，包含跨文件重构、竞态修复与浏览器级回归验证。
- 排查出"触摸设备误判导致光标消失"的产品级根因（pointer:coarse 判定替代 maxTouchPoints），并修复对象池代际令牌竞态。
- 通过招聘市场大数据分析（BOSS直聘官方统计+21个真实JD样本）驱动技术选型，将 RAG/MCP/Eval 等 100%/86%/67% 提及率的技能全部落地为可运行代码。

## 工作观
AI 是工具、人才是目的——Agent 负责执行密度，人负责问题定义与验收标准。所有产出必须通过可机器验证的测试才算完成。
