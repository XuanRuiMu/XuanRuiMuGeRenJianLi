# 于翔堃项目全景

于翔堃是刚毕业的计算机本科应届生，核心能力是用 AI Agent 解决问题、完成工作。工作区内项目包括：本简历站（Astro 7 服务端渲染 + 内嵌游戏世界，已上线公网）、NEON CYBER 游戏世界（7 款原创小游戏平台，原生 JavaScript + Canvas 2D，零引擎依赖）、智能体工坊（全栈 AI Agent 平台，Python FastAPI + MySQL + 自研 ReAct 运行时 + RAG 混合检索 + MCP 网关 + SSE 流式，已上线公网，含三级降级容错）、AI 简历匹配平台（Java 17 + Spring Boot 3.5 + Data JPA + Redis，JD 与简历匹配度分析，LLM 不可用时降级本地规则引擎，JUnit 5 + MockMvc 测试，Dockerfile 多阶段构建 + docker-compose 编排）、网上村委会业务办理系统（毕业设计，Java + Spring + MyBatis，8 模块 12 表 88 个端点，366 个测试用例，已通过答辩）、会解压的外星人 AI 情绪陪伴应用（Vue 3 + Express + SQLite，SSE 打字机流式、9 类情绪识别）。技术覆盖 TypeScript/Astro/React/Vue 前端、Python FastAPI 异步后端、Java Spring 后端、MySQL/SQLite/H2、Redis 缓存与限流、AI Agent 工作流与 Skill 开发。

注意：以上项目均为个人独立完成的自研与课程项目，非企业生产环境；他本人无企业实习与正式工作经历。Linux 生产运维经验有限。
