- **每天 10–15 个有效投递**（直聊 + 追问），别一天海投 100 份
- **70% 精投 + 20% 内推 + 10% 海投**（精投 = 按 JD 微调简历与附言）
- **投递跟踪表**必做：公司 / 岗位 / 渠道 / 日期 / 状态 / 下一步 / 背调要点
- 面试后 30 分钟内写复盘

## 防骗（4 类高发）

1. **培训贷 / 招转培**：面试后说你"能力不足"要求付费培训 → **正规招聘不收费**
2. **付费内推 / 保 offer**：冒充名企 HR 收费 → 正规企业绝不收
3. **虚假高薪引流**：薪资远高于市场，实际是销售/保险 → 投前用天眼查/企查查核资质
4. **扣证件、收押金/体检费/建档费** → 一律拒绝

遇以上任一情况：立即终止，保留聊天记录与缴费凭证，拨 **12333** 举报。
